## 实施顺序

1. 编写归一化分类与纯恢复决策，先固定 E0/C1/E1/C2/E2 语义。
2. 实现事务存储、去重、动作意图与单实例锁。
3. 实现 JSONL 双向通信、受管 Codex 适配器与可重复故障演练适配器。
4. 实现守护编排、退避调度、停止/暂停、启动失败熔断和重启核对。
5. 提供本机 API、SSE、历史、告警与本次批准入口。
6. 完成本机中文面板及插件，制作打包/启动工具。
7. 跑边界测试、进程协议测试、真实无模型调用握手测试及浏览器验证。
8. 更新逐项验收、实际限制与下一阶段计划。

## 持久化规范

每阶段完成更新本文件与根目录 PROJECT_STATE.md。重要设计变化先记录，再实现。验证失败及修复要记录到最终报告；没有实际运行的验证不能标记通过。
