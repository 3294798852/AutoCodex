# 已有会话监测：需求、设计与验收

版本目标：0.5.0；日期：2026-09-14。

## 用户需求

不要求重新创建 Codex 会话。面板提供“已有会话”，自动列出当前 Codex 数据目录中的桌面、CLI、IDE 与 app-server 会话。用户按标题搜索、翻页或查看归档，点击“加入监测”即可查看原会话后续活动、输出与异常；不用填写 ID、目录或原任务。

## 指标

- 支持正在工作和已经结束的本机会话；会话后续再次运行时继续监测。
- 每秒检查已选会话的新记录；正常本机负载下，记录落盘至页面更新目标不超过 3 秒。模型尚未落盘的流式内容不作实时承诺。
- 初次读取仅扫描日志末尾最多 2 MiB；增量每轮最多 1 MiB，保留不完整行至下轮，超大单行有界跳过并显示覆盖提示。
- 与受管任务合计最多 20 个活动监测；重复加入返回原任务。选择和读取位置持久化，服务重启继续观察，不重放旧告警。
- 区分最近有活动、明确完成、明确中断、记录异常、等待用户、状态待确认、记录不可读。超过 30 秒没有新的活动证据不继续标成运行；默认 10 分钟没有活动证据且没有明确终态时发一次核对提醒。
- 异常记录与提醒可查；命令失败单独展示，不能据此把整个会话判定为致命失败。不将普通正文中的“error”当作运行错误。
- 停止监测只停止本服务读取；不能中断原客户端。仅监测时，自动续发和免打扰批准不作用于该会话。需要这两项功能，可在面板“移交并继续”，明确确认原客户端已停止后接入既有恢复核心。
- 路径从所选 Codex 的 thread/list、thread/read 自动获取；沿用现有 CLI 自动发现/手动路径与 CODEX_HOME 环境。无固定用户目录；不通过网页接收任意日志路径。
- 列表和加入接口仅供本机管理面板使用；原鉴权、跨站防护与插件查询范围保留。输出脱敏，不保存推理正文。

## 协议实证与选择

官方 app-server 文档明确 thread/read 不订阅，不加载会话，thread/loaded/list 仅反映当前服务内存。thread/list 支持分页、标题搜索、归档、来源和模型提供方过滤。

本机 CLI 0.153.4 的独立 stdio 服务成功列出桌面会话，但对正在工作的本项目返回 notLoaded，历史最后回合甚至返回 interrupted；因此不能用这些值推断桌面工作已停止。此版本的 daemon version 在 Windows 返回“only supported on Unix platforms”，不能声称已连接桌面共享服务。

采用官方接口发现元数据，再只读增量跟踪接口返回的 JSONL 记录。已观察到 event_msg/task_started、task_complete、turn_aborted、item_completed（AgentMessage、CommandExecution 等）以及 token_count。兼容旧式 agent_message/exec_command_end 与明确 error/stream_error。未知记录跳过，终态只认明确事件。此日志格式是版本兼容层，未来格式变化应更新解析器或显示状态待确认，不能猜测。

## 实现分层

1. CodexAdapter：列表和元数据只读接口；独立 rollout 读取器负责有界增量、换文件与损坏行。
2. ExistingSessions：观察任务、持久化读取位置、状态推导、提醒去重及移交控制。与 Supervisor 共用存储和 SSE，但观察任务完全排除自动派发、恢复与批准路径。
3. 本机 API：已有会话查询/加入；任务控制支持停止/恢复监测、立即检查、明确移交。
4. 页面：现有会话选择器、自动填写元数据、独立观察状态说明；保留新建受管任务入口。

## 验收计划

隔离日志覆盖活动/完成/重开/错误/中断/命令失败/损坏/半行/截断/删除/恢复/重复加入/重启与权限。隔离真实 Codex 验证历史发现、活跃会话可观察且未 resume、停止监测无 interrupt。浏览器验证搜索分页、加入和移交入口、SSE 更新、停止重启和窄屏。不得向用户正在运行的任务发送测试消息。

依据：https://learn.chatgpt.com/docs/app-server#threads
